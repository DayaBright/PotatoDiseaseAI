# PotatoDiseaseAI 🥔🤖

**Detección automática de enfermedades en cultivos de papa mediante Visión Artificial.**

Este proyecto es una aplicación móvil desarrollada para ayudar a los agricultores a identificar enfermedades en las plantas de papa de forma **offline**, utilizando modelos de Deep Learning optimizados para dispositivos móviles.

## 🚀 Características
* **Detección en tiempo real:** Clasificación de enfermedades usando la cámara del dispositivo.
* **Modo Offline:** No requiere conexión a internet para realizar inferencias.
* **Arquitectura Robusta:** Desarrollada con Kotlin, Jetpack Compose y MVVM.
* **Transparencia:** Implementación de Grad-CAM para visualizar qué áreas analiza el modelo.

## 🛠️ Tecnologías utilizadas
* **Android:** Kotlin, Jetpack Compose, CameraX, Room.
* **IA/ML:** TensorFlow Lite, Keras, OpenCV.
* **Hardware de prueba:** Redmi Note 14 Pro 5G.
